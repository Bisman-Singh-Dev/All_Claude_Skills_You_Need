# Python Editing Master — Claude Skill

Install/use this skill by making the `python-editing-master` folder available to Claude as a custom skill.

Contents:
- `SKILL.md` — main skill instructions
- `references/` — focused image, video/audio, office/PDF, and batch workflow guides

The skill guides Claude to inspect files, choose suitable Python tools, preserve originals, perform edits, validate outputs, and report limitations honestly.

Note: the skill is an instruction pack, not a bundled Python runtime. Claude still needs access to the relevant files, execution environment, and libraries/tools for actual edits.
