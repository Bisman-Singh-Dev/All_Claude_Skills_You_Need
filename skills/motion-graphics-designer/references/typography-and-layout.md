# Typography and Layout Reference

- Use a clear type hierarchy: headline, supporting text, labels, metadata.
- Limit the number of type families and weights.
- Align to a consistent grid and maintain deliberate margins.
- Check line breaks, optical alignment, tracking, and contrast.
- Preserve comfortable reading time.
- Animate text in meaningful groups; avoid random character-level movement.
- Verify glyph coverage and font licensing.
- Keep key content inside platform-safe areas when designing for social video.
