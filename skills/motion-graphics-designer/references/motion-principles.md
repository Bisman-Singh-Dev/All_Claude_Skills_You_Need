# Motion Principles Quick Reference

## Before animating
- Identify the focal point and intended viewer attention.
- Define the start state, end state, and reason for movement.
- Decide whether the motion is expressive, informational, or functional.

## Curve vocabulary
- Ease-out: fast start, gentle settle; useful for entrances.
- Ease-in: gentle start, fast exit; useful for departures.
- Ease-in-out: controlled acceleration and deceleration; useful for state changes.
- Spring: responsive overshoot; use only when appropriate to the material and tone.
- Linear: constant speed; useful for mechanical or continuous motion.

## Polish pass
Review motion at normal speed, half speed, and frame-by-frame. Check whether easing, overlap, anticipation, and holds help the message. Remove any movement that adds noise without adding meaning.
