# Short-Form Video Editor — Claude Skill

A custom Claude skill for editing vertical short-form content for Reels, TikTok, and YouTube Shorts.

Contents:
- `SKILL.md` — core editorial and technical instructions
- `references/editing-checklist.md` — final review checklist
- `references/ffmpeg-recipes.md` — practical FFmpeg starting points
- `references/caption-design.md` — caption design standards

This is an instruction pack, not a bundled editor or Python runtime. Actual editing requires access to the footage, an execution environment, and the relevant tools (especially FFmpeg).
