# Short-Form Editing Checklist

## Story
- [ ] Strong opening moment
- [ ] Context is clear
- [ ] No unnecessary repetition
- [ ] Payoff is present
- [ ] Ending feels intentional

## Picture
- [ ] 9:16 composition is deliberate
- [ ] Subject remains in frame
- [ ] No awkward crops
- [ ] Color is consistent
- [ ] Text is readable and within safe margins

## Audio
- [ ] Dialogue is clear
- [ ] No clipping
- [ ] Music is appropriately ducked
- [ ] Effects are not excessive
- [ ] No sync drift

## Captions
- [ ] Transcript proofread
- [ ] Timing checked
- [ ] Names and technical terms correct
- [ ] Captions do not cover faces or UI
- [ ] SRT/VTT exported if useful

## Export
- [ ] Correct resolution and aspect ratio
- [ ] Correct duration and frame rate
- [ ] Audio and video present
- [ ] Start, middle, and end inspected
- [ ] File re-opened successfully
